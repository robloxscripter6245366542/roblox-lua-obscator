How it works

MoonVeil. Every string sits in the source as end)(data, key) and is rebuilt with a repeating XOR — data[i] xor key[(i-1) mod #key + 1]. Symmetric and stateless, so the whole table falls out in one pass.

WeAreDevs. The loader keeps a string table W={"\ddd…"} of custom-alphabet Base64, and a lookup table C={…} that is the shuffled alphabet. Rebuild the alphabet from C, then decode every entry — no execution needed. Tick Deep resolve to go further: it statically replays the runtime W[a],W[b]=W[b],W[a] permutation, reads the accessor offset from D(x)=W[x+n], and evaluates every arithmetic-encoded D(bignum) index — mapping all ~900 indirection calls back to the strings they fetch, with usage counts.

Scope. An analysis lens — for understanding scripts before you run them and studying obfuscation. Not for stripping protection from code someone else obfuscated to guard their work.
