Output —

🔤

Identifier renaming

A real Lua/Luau parser resolves scope, then renames every local, parameter and loop variable to opaque names — globals and fields stay intact so the script still runs.

🔐

String encryption

Each string literal is XOR-encrypted with a per-build keystream and rebuilt at runtime through a decoder function. The plaintext never appears in the file.

🧮

Constant encryption

Number literals are rewritten as arithmetic and bitwise expressions so a quick scan can't read the magic values your script depends on.

🌀

VM-style wrapper

The whole chunk is folded into a Luraph-signature return(function(...) … end)(...) dispatch closure — vararg & return values preserved.

🛡️

Anti-tamper

A watermark checksum is embedded and re-verified at runtime; edit the banner and the guard quietly bails, exactly like Luraph's integrity layer.

🏷️

Signature banner

Ships with the classic Luraph header — version, serial, watermark, preset and seed — so the output is instantly recognisable as Luraph-format.

How this relates to the real Luraph. This is a free, open, client-side obfuscator that emits code in the Luraph format / style for learning and lightweight protection. It is not affiliated with, and does not reproduce, the proprietary Luraph VM. Like every self-contained obfuscator it raises the effort to read your code and defeats casual copy-paste — it is not an unbreakable protection boundary, since the decoder and key must ship with the script to run. Use it to understand the format and to lightly protect scripts you own.
